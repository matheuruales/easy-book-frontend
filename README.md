# Navaja — frontend

Interfaz web para gestionar una única marca de barbería con múltiples sedes, construida con React, TypeScript y Vite.

## Ejecutar en local

1. Comprueba que el backend esté disponible en `http://localhost:8080`.
2. Instala las dependencias con `npm install`.
3. Inicia el frontend con `npm run dev`.
4. Abre `http://localhost:5173`.

La dirección del backend se configura en `.env` mediante `VITE_API_URL`.

## Comandos

- `npm run dev`: inicia el entorno local.
- `npm run build`: valida tipos y genera la versión de producción.
- `npm test`: ejecuta las pruebas.

## Base visual

La interfaz sigue principios de diseño de Apple: jerarquía clara, superficies translúcidas, profundidad contenida, respuesta inmediata al tocar y movimiento reducido cuando el sistema lo solicita.
